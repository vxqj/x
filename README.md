# link-hub

Dead simple Next.js link hub. Black background, pill dock at the bottom with your socials, macOS-style magnify on hover.

## Run locally

```bash
npm install
npm run dev
```

## Edit your links

Open `app/Dock.js` and edit the `LINKS` array — swap in `href`s or add more entries (icons for tiktok/x/github/discord are already included).

## Deploy

Push to a repo, import it on Vercel, done — no env vars or config needed.
